# System Overview

This document describes the architecture and major subsystems of the Smart Agri Rover.

## Main Subsystems

- Rover control and navigation
- Computer vision and tomato ripeness detection
- Robotic harvesting
- Soil nutrient analysis
- Raspberry Pi and Arduino-based control

## System Architecture

The rover integrates robotics, computer vision, soil sensing, and robotic harvesting into a multifunctional agricultural platform.

## Current Prototype

The current prototype uses Wi-Fi/remote control for rover operation. Autonomous navigation and path planning are considered future improvements.
