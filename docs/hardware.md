# Hardware

## Main Components

The Smart Agri Rover consists of the following major hardware components:

- Raspberry Pi 4
- Arduino Mega
- Arduino UNO
- USB camera
- DC motors
- Monster motor driver
- 12V battery
- Buck converter
- NPK soil sensor
- RS-485 module
- Six MG996R servo motors
- 6-DOF robotic arm
- Two-finger harvesting claw

## Processing and Control

The Raspberry Pi 4 is used for onboard processing and computer vision, while Arduino controllers are used for hardware control and sensor interfacing.

## Robotic Arm

The rover incorporates a 6-degree-of-freedom robotic arm with six servo motors. The end effector uses a two-finger mechanism with blades for tomato harvesting.
