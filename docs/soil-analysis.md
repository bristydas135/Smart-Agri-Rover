# Soil Analysis

## Overview

The rover incorporates an NPK soil sensing system for measuring:

- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)

## Sensor Communication

An RS-485 communication module is used to transmit the sensor data to an Arduino UNO.

## Example Measurements

| Nutrient | NPK Sensor | Aqualink |
|---|---:|---:|
| Nitrogen | 74 mg/kg | 54 mg/kg |
| Phosphorus | 68 mg/kg | 73 mg/kg |
| Potassium | 181 mg/kg | 172 mg/kg |
